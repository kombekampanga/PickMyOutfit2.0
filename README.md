# PickMyOutfit2.0

The React and Typescript version of my PickMyOutfit Application! Woohooo
Check it out here: https://pickmyoutfit-website-frontend.onrender.com/

## Running locally
To run this application run the followng commands from the base /PickMyOutfit2.0 path

`npm run backend`

Then in a separate terminal run

`npm run frontend`
